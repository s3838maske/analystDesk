# Sample files (synthetic)

All numbers here are made up, for fictional DEMO companies, to try the app end to end. They are not real financial data.

- `demo_financials_template.xlsx`: standard template, DEMOALPHA (subject) + 3 peers, FY2021–FY2025, ₹ crore. Contains two deliberate errors (FY2023 balance sheet off by ₹37.5 cr; FY2024 capex with the wrong sign).
- `demo_gamma_terminal_export_lakh.xlsx`: a wide "terminal export" layout in ₹ lakh, for the column-mapping screen (upload it under a source name such as "terminal export").
- `demo_prices.csv`: quarter-end closes and current shares outstanding.
